## Project Description

Shuttu🎀 is a satirical AI search engine that refuses to give straightforward answers.

Instead of answering a user's search query, Shuttu repeatedly asks unnecessary, increasingly absurd questions about their intentions, choices, and life decisions. After enough questioning, it finally provides the most useless answer possible: **"We don't know."**

The project is a humorous parody of modern AI assistants and search engines that keep asking users for clarification instead of simply answering.

---

## The Problem (that doesn't exist)

Modern AI assistants ask too many questions.

You ask:

> "What's the weather tomorrow?"

And instead of getting the weather, you might get asked about your location, plans, intentions, preferences, emotional state, and possibly your childhood.

Shuttu🎀 solves this extremely serious and completely imaginary problem by making the situation dramatically worse.

---

## The Solution (that nobody asked for)

We created a search engine that intentionally refuses to search.

Shuttu🎀:

1. Takes your search query.
2. Asks an unnecessary question.
3. Lets you defend yourself using quick-response buttons or text input.
4. Asks another question.
5. Gets progressively more ridiculous.
6. Eventually offers a **"SEARCH ANYWAY"** button.
7. Still questions your decision.
8. Finally shows fake search results saying:

> **"We don't know."**

But don't worry — it learned a lot about you.

# Technical Details

## Technologies/Components Used

### For Software:

- **HTML5** — Web page structure and interface
- **CSS3** — Responsive UI, animations, cards, buttons and visual styling
- **JavaScript** — Application logic and interactions
- **Groq Cloud API** — AI-powered satirical responses
- **Built-in Satirical Engine** — Offline fallback response system
- **Web Audio API** — Typewriter clicks, pops and alert sounds
- **LocalStorage API** — Search history, audio preferences and application settings
- **Google Fonts**
  - Plus Jakarta Sans
  - JetBrains Mono
- **VS Code** — Development environment
- **Live Server** — Local development and testing

The application uses a built-in satirical response engine when no API key is available, allowing the project to run without external AI configuration. :contentReference[oaicite:1]{index=1}

The optional AI mode connects directly to Groq's API and supports selectable Groq models. :contentReference[oaicite:2]{index=2}

### For Hardware:

- No special hardware required.
- Any computer capable of running a modern web browser.
